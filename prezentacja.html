Research Question, Hypothesis & Motivation

Core comparison: Passive learning asks for labels blindly, while Active Learning asks only about the hardest 50/50 borderline cases.

Research Question

How many labeled examples can I save by using Active Learning (Uncertainty Sampling and Query-By-Committee) compared to passive Random Sampling to reach the same accuracy on heart attack data?

Hypothesis

I Expect 30%–40% Saved Labels

If the model picks only the most uncertain patients (near the 50/50 boundary) or where a committee of models disagrees, it will reach 95% of full-data Accuracy and F1-score using 30% to 40% fewer labels than random sampling.

When can this hypothesis fail? If Active Learning picks extreme data errors (outliers) instead of real borderline patients, it will not beat random sampling.
Motivation

Why This Matters in Medicine

  • High Labeling Cost: Collecting raw blood tests is cheap, but paying doctors to diagnose and label cases is slow and expensive.
  • Smarter Data Choice: Instead of building a bigger model, I let a simple model choose which patients are most useful to label next.
  • Real Clinical Data: Medical tables have both strong markers and measurement errors, so I can test when Active Learning works and when it fails.
Takeaway The main goal is not to build a complex model, but to reach the same medical accuracy with much less labeled data.

Anchor Paper & Candidate Dataset

Theory vs. Practice: Settles (2010) provides the mathematical query methods, and my 1,319-patient dataset lets me test them on real clinical data.

Anchor Paper

Active Learning Literature Survey

Burr Settles (2010) · University of Wisconsin–Madison
Main Idea:

A model reaches high accuracy with much fewer labels if it can choose which unlabeled data points to ask about next.

3 Methods I Take From This Paper:
  • Pool-Based Loop: Start with a small labeled set and pick new samples step-by-step from a large unlabeled pool.
  • Uncertainty Sampling: Pick patients where the model is least sure (closest to 50/50 probability).
  • Query-By-Committee (QBC): Three models vote, and the algorithm picks the patient where they disagree the most.
Key Limitation (Settles Sec. 3.6): Uncertainty Sampling can accidentally pick extreme outliers near the boundary instead of typical patients.

Baselines, Active Methods & Fair Protocol

Fair comparison: Every method starts with the exact same 20 patients, uses the same models, and is tested on the same locked 330-patient test set.

1. Baselines

Passive & Full-Data

  • Random Sampling: Pick 10 random patients from the unlabeled pool in each step.
  • Full-Data Model: Train on 100% of the training pool (989 rows) to see the top possible score.
  • Equal Start: Every method starts with the exact same 20 balanced samples.
2. Active Strategies

Uncertainty & QBC

  • Entropy Sampling: Pick patients where prediction confidence is lowest.
  • Margin Sampling: Pick patients closest to the 50/50 decision boundary.
  • Query-By-Committee (QBC): 3 models (LogReg, Random Forest, MLP) vote, and the algorithm picks the most disagreed sample.
3. Evaluation Metrics

How I Measure Success

  • Learning Curves: Plot Accuracy and Macro F1-score from 20 up to 300 labeled samples.
  • Area Under Curve (AULC): Average score across the whole labeling budget.
  • Saved Labels (%): How many fewer labels are needed to reach 95% of the full-data score.
4. Four Rules for Fair Comparison & Zero Data Leakage
No Data Leakage Lock 25% of data (330 rows) as a fixed test set. Fit StandardScaler only on currently labeled data.
Same Step Loop Start with 20 balanced samples and add 10 new samples per step up to 300 labels.
5 Random Seeds Repeat every experiment across 5 random seeds (42, 100, 2026, 7, 99) and plot mean ± std.
Same Base Models Use the exact same Logistic Regression and Random Forest settings for all strategies.
Takeaway Because I lock the test split and run 5 random seeds, any improvement comes strictly from smarter sample selection, not luck or leakage.

Class 3 Protocol: Hypothesis, Splits, Metrics & Comparisons

Controlled Benchmark: I lock all experimental parameters before running code — 330 holdout patients, 5 random seeds, zero data leakage, and 2 targeted stress tests.

1. Refined Hypothesis (From Literature)

Label Savings vs. Outlier Sensitivity

  • Main Claim (H₁): On Heart Attack.csv, Margin, Entropy, and QBC will reach 95% of the full-data Macro F1-score using 30%–40% fewer labels than passive Random Sampling (Lu et al., 2025).
  • Outlier Claim (H₂): Removing extreme measurement errors (like impluse = 1111) will improve Uncertainty Sampling in early steps (Settles, 2010).
2. Locked Data Splits & Zero Leakage

1,319 Total Patients (Heart Attack.csv)

  • Locked Test Set (25% = 330 rows): Separated once at the start with the same class balance, and never used for selection or scaling.
  • Training Pool (75% = 989 rows): Divided into starting labeled set |L0| = 20 balanced samples (10 positive, 10 negative) and unlabeled pool |U0| = 969 rows.
  • Zero Leakage Rule: StandardScaler is fitted strictly on the current labeled set Lt at each step.
3. Evaluation Metrics (Across 5 Seeds)

How I Measure Performance

  • Learning Curves: Test Accuracy and Macro F1 measured from 20 to 300 labels (adding 10 labels per step = 29 steps).
  • Area Under Curve (AULC): Single summary score of label efficiency across the whole budget (Lu et al., 2025).
  • Saved Labels (%): Labels needed to reach 95% of the Full-Data (989 rows) score, reported as mean ± std over 5 seeds (42, 100, 2026, 7, 99).
4. Comparison & Ablation Plan

Baselines, Active Methods & Stress Tests

  • Baselines: Passive Random Sampling + Full-Data Upper Bound (trained on all 989 rows).
  • Active Strategies: (1) Entropy Sampling, (2) Margin Sampling, and (3) Query-By-Committee (QBC) across LogReg, Random Forest, and MLP.
  • Stress Tests (Class 5–6): Raw pool vs. cleaned pool (impluse < 300), and all features vs. removing troponin.
Takeaway By freezing my test split and refitting scalers only on labeled subsets, I prevent data leakage completely and establish a reproducible benchmark for Class 4.
